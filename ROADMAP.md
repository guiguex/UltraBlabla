# 🗺️ UltraBlabla Roadmap

La vision d'UltraBlabla est de devenir l'interface vocale IA la plus fluide et personnalisable au monde. Voici notre plan de développement.

## 🚀 Phase 1 : Stabilisation "Edge" (Actuelle)
- [x] Remplacement du stack local (VOSK/QWEN) par une architecture Cloudflare AI Edge.
- [x] Refonte de l'algorithme VAD (Voice Activity Detection) en client-side.
- [x] Conteneurisation Docker complète pour le backend.
- [x] Compatibilité Android 15 & SDK 35 (Edge-to-Edge).

## 🌌 Phase 2 : Personnalisation Holographique (Q4 2026)
- **Profiles Vocaux IA** : Permettre à l'utilisateur de basculer entre différentes personnalités d'IA (Assistant formel, Narrateur épique, Compagnon décontracté).
- **Thèmes Neuronaux Dynamiques** : Adaptation de la couleur de l'hologramme en fonction de l'humeur détectée par le LLM.
- **Support Multilingue Temps-Réel** : Ajout de l'espagnol et de l'anglais via sélection dynamique.

## ⚡ Phase 3 : Mode Hors-Ligne Hybride (Q1 2027)
- **Retour du Local ML** : Intégration de modèles SLM (Small Language Models) embarqués dans l'APK Android (via MediaPipe ou ExecuTorch) pour un fonctionnement sans réseau (Offline Fallback).
- **Synchronisation Sécurisée** : Sauvegarde des historiques de discussion avec chiffrement de bout-en-bout.

## 🔮 Phase 4 : Écosystème Ultra (2027+)
- **API Ouverte** : Permettre l'intégration d'UltraBlabla dans d'autres projets domotiques.
- **Wearables** : Support expérimental pour les montres connectées (WearOS) via une interface ultra-minimaliste.
